## Alignments

Sorted, indexed BAM files for all eight libraries against both the genome
and the transcriptome, together with their `samtools stats`, `flagstat` and
`idxstats` output. Excluded here on account of size (order of 10 GB across
all libraries). Regenerated by running the pipeline as described in the
main README; summary alignment statistics for every library are already
reproduced in `results/multiqc` once that stage completes locally.
