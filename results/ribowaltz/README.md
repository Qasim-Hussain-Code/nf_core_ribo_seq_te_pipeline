## riboWaltz P-site calibration

Per-library P-site offset calibration (one plot per read length considered),
codon usage, 5'/3' end heatmaps and metagene profiles produced by riboWaltz
for all four Ribo-seq libraries. Excluded here for size (over 100 PDFs);
the single most informative figure from this output, the P-site metagene
profile around the start codon, is reproduced in the main README, and the
underlying offset tables are regenerated in full by re-running the
pipeline.
