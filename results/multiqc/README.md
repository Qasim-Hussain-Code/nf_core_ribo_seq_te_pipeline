## MultiQC report

An aggregated quality-control report spanning FastQC, Cutadapt, SortMeRNA,
STAR and samtools output for all eight libraries. Excluded here for size;
it is regenerated in full by re-running the pipeline, and the two QC
figures most relevant to data quality (ribosome P-site enrichment at the
start codon, and the reading-frame periodicity of ribosome footprints) are
reproduced directly in the main README and in `results/riboseq_qc`.
